# Git Visualizer

A modern, striking Git visualization tool built with React and Vite.

## Features

- **Visual Graph**: Red threads connect commits (notes) with pins.
- **Branching**: Visualize branches as threads.
- **Console**: Execute git commands to interact with the graph.
- **Commands Supported**:
  - `git commit -m "message"`
  - `git branch <name>`
  - `git checkout <name>`
  - `git log`

## How to Run

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open your browser at the provided URL (usually http://localhost:5173).
